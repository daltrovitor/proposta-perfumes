# PROJETO DE ORÇAMENTO TÉCNICO E FINANCEIRO — ECOSSISTEMA NXTGEN

**Documento de Escopo e Investimento por Fases**  
**Versão:** 2.1  
**Referência:** Escopo Funcional do App, Especificação Técnica de Pagamentos e Apresentação Institucional  

Aplicação web interativa da proposta comercial e técnica para o ecossistema digital **NXTGEN**.

Consulte a íntegra da proposta em [PROPOSTA_NXTGEN.md](./PROPOSTA_NXTGEN.md) ou execute o projeto com `npm run dev` para visualizar a proposta interativa completa no navegador.

---

## Estrutura do Projeto
- `app/page.tsx`: Interface interativa da proposta (detalhamento por fases, orquestrador, simulador de parcelas, entregas técnicas e contato WhatsApp).
- `app/layout.tsx`: Configuração de metadados e identidade visual da proposta.
- `PROPOSTA_NXTGEN.md`: Especificação técnica e financeira na íntegra.
